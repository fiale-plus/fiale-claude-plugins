# Hub Music - Contextual Music Configuration

Configure automatic music reactions to status events.

## Usage

- `/hub-music` - Show current config and wizard
- `/hub-music enable` - Enable contextual music
- `/hub-music disable` - Disable contextual music
- `/hub-music status` - Show current settings
