# Vibes

Run the vibes control script and print its output:

```bash
bash "${CLAUDE_PLUGIN_ROOT}/bin/vibes.sh" $args
```

**Modes:**
- `jazzy` — 63 BPM Chet Baker cool jazz, Autumn Leaves changes in Bb major
- `cafe` — 72 BPM Jobim bossa nova, Corcovado / Black Orpheus cycle in A minor
- `synth` — 100 BPM retro 80s synthwave, Kavinsky-style Em arpeggios over sweep pads
- `off` — graceful fade out and stop
