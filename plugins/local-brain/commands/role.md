---
description: Set this machine's role — source (capture only), aggregator (synthesis), or standalone (both)
---

Configure what this machine does in the local-brain pipeline. Run once per machine, or re-run to change role.

## Roles

| Role | Captures sessions | Synthesizes | Scheduling | Vault sync |
|------|:-----------------:|:-----------:|:----------:|:----------:|
| **source** | ✓ | — | — | Receive Only |
| **aggregator** | — | ✓ | cron/launchd | Send & Receive |
| **standalone** | ✓ | ✓ | cron/launchd | Send & Receive |

**Source**: a workhorse laptop. Sessions are queued automatically via the Stop hook. The vault stays up to date via Syncthing (receive-only — no local writes). No synthesis runs here.

**Aggregator**: a machine that's reliably online (desktop, server). Pulls transcripts from source machines, synthesizes, writes the vault. Other machines get the notes via Syncthing.

**Standalone**: single machine doing everything. The current default.

---

## Steps

### 1. Read current config

```bash
cat ~/.claude/local-brain/config.json 2>/dev/null || echo "{}"
```

Show current role if set.

### 2. Ask for role

> "What role should this machine play?
> 1. **source** — capture sessions only, no synthesis here
> 2. **aggregator** — synthesize sessions from this and other machines
> 3. **standalone** — capture and synthesize on this machine (single-machine setup)"

### 3. Apply role

#### If **source**:

Update config:
```json
{
  "vault_path": "<existing vault_path>",
  "role": "source"
}
```

Tell the user:
> "Source role set. This machine will queue sessions automatically — no synthesis will run locally.
>
> **Syncthing**: set the `brain` folder to **Receive Only** on this machine so it only reads notes from the aggregator:
> 1. Open http://127.0.0.1:8384
> 2. Click the `brain` folder → Edit
> 3. Advanced tab → Folder Type → **Receive Only**
> 4. Save
>
> The aggregator machine needs to pull transcripts from here to synthesize them. See: `/brain-role` on the aggregator."

Check and remove any existing local-brain scheduling (see `/brain-schedule --remove-all`):
```bash
# Check for existing crontab entries
crontab -l 2>/dev/null | grep -i "local-brain\|/synthesize\|/brain-reflect"
```

If found, ask: "Remove existing synthesis scheduling from this machine? (Y/n)" and if yes, run `/brain-schedule --remove-all` logic (see that command).

#### If **aggregator**:

Ask: "Which source machines should this aggregator pull from? Enter SSH connection strings, one per line (e.g. `pavel@192.168.1.10`). Press Enter twice when done. Leave blank to skip (pull manually)."

Collect as a list. Update config:
```json
{
  "vault_path": "<existing vault_path>",
  "role": "aggregator",
  "sources": [
    { "host": "192.168.1.10", "user": "pavel", "name": "laptop2" }
  ]
}
```

Parse each entry as `user@host` or `user@host:port`. Use the hostname as `name`.

Create the pull script at `~/.claude/local-brain/pull-sources.sh`:
```bash
#!/bin/bash
# Pull transcripts from source machines
# Generated by /brain-role — edit sources in ~/.claude/local-brain/config.json

set -e
IMPORT_DIR="$HOME/.claude/local-brain/import"
PLUGIN_ROOT="<CLAUDE_PLUGIN_ROOT>"

<for each source>:
echo "Pulling from <name> (<user@host>)..."
mkdir -p "$IMPORT_DIR/<name>"
rsync -avz --ignore-errors \
    -e "ssh -o ConnectTimeout=10 -o BatchMode=yes" \
    "<user@host>:~/.claude/projects/" \
    "$IMPORT_DIR/<name>/projects/"

python3 "$PLUGIN_ROOT/scripts/backfill.py" "$IMPORT_DIR/<name>/projects"
</for each source>

echo "Done. Run /synthesize to process queued sessions."
```

Make it executable:
```bash
chmod +x ~/.claude/local-brain/pull-sources.sh
```

Tell the user to ensure **passwordless SSH** is set up for each source:
```bash
ssh-copy-id pavel@192.168.1.10   # run once per source machine
```

**Syncthing**: vault should be **Send & Receive** (the default) — no changes needed.

Then run `/brain-schedule` to install synthesis scheduling.

#### If **standalone**:

Update config:
```json
{
  "vault_path": "<existing vault_path>",
  "role": "standalone"
}
```

Tell the user vault sync should be **Send & Receive** (the Syncthing default).

Then run `/brain-schedule` to install synthesis scheduling.

### 4. Summary

Print a role-specific summary:

**Source:**
```
✓ Role: source
  Sessions queued automatically via Stop hook
  No local synthesis
  Vault: set Receive Only in Syncthing (instructions above)
  Aggregator will pull your transcripts from: ~/.claude/projects/
```

**Aggregator:**
```
✓ Role: aggregator
  Sources configured: <list>
  Pull script: ~/.claude/local-brain/pull-sources.sh
  Vault: Send & Receive (Syncthing default)
  Next: run /brain-schedule to set up synthesis cron
```

**Standalone:**
```
✓ Role: standalone
  Captures and synthesizes on this machine
  Vault: Send & Receive (Syncthing default)
  Next: run /brain-schedule to set up synthesis cron
```
