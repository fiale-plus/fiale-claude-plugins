---
description: Weekly pattern synthesis — reads recent session notes and extracts wins, blockers, themes, and suggested Polaris updates
---

Synthesize patterns across recent sessions into a weekly insight note. Run at the end of a week or whenever you want a retrospective.

## Steps

### 1. Load config and locate session notes

```bash
cat ~/.claude/local-brain/config.json
```

Get `vault_path`. List available session notes:
```bash
ls VAULT_PATH/_AI/sessions/ | sort
```

### 2. Determine scope

Ask the user:
> "How many days back should I look? Default is 7 (last week). Enter a number or press Enter."

If they say Enter or "default", use 7 days. Call this `DAYS`.

Calculate the date range: today minus DAYS days through today.

### 3. Read session notes in range

For each date in the range that has a file in `_AI/sessions/`, read the full file.

Also read `VAULT_PATH/Polaris/top-of-mind.md` if it exists.

### 4. Synthesize patterns

Using your own reasoning across all the session content, produce a reflection covering:

**Theme distribution** — which primary themes appeared and how often (building / debugging / researching / planning / configuring)

**Energy pattern** — was energy generally high, medium, or low? Any notable shifts?

**Wins** — concrete things that got done or figured out (from outcome=done sessions and decisions_made)

**Recurring blockers** — anything that came up more than once as a blocker or unexplored thread

**Decisions that compounded** — decisions from earlier sessions that appeared again later (shows they mattered)

**Learnings worth keeping** — the most durable things learned across the week

**Alignment signal** — overall alignment_with_polaris across sessions; any drift?

**Suggested Polaris updates** — based on what you actually worked on vs what top-of-mind.md says, suggest specific edits to keep it current

**Thread worth picking up** — the most interesting unexplored_thread from the week

**Next week focus** — synthesized suggested_next items into a coherent week-ahead recommendation

### 5. Write insight note

Determine the ISO week: `python3 -c "from datetime import date; d=date.today(); print(f'{d.year}-W{d.isocalendar()[1]:02d}')"`

Write to `VAULT_PATH/_AI/insights/YYYY-Www.md`. If the file already exists, prepend a new section (don't overwrite — same-week re-runs should accumulate, not replace).

Format:
```markdown
# Week YYYY-Www Reflection
_<start_date> – <end_date> · <N> sessions · <N> days_

## Theme distribution
<theme>: N sessions · <theme>: N sessions · ...

## Wins
- ...

## Recurring blockers
- ...

## Durable learnings
- ...

## Alignment: <high|medium|low|mixed>
<1-2 sentences on alignment trend>

## Suggested Polaris updates
- [ ] <specific suggested edit to top-of-mind.md>
- [ ] ...

## Thread worth picking up
<the most interesting unexplored thread>

## Next week focus
<concrete recommendation for what to prioritise>

---
_Generated by /brain-reflect on <today>_
```

### 6. Report

Tell the user:
- Which sessions were read (dates + count)
- Where the insight note was written
- The suggested Polaris updates (so they can act on them without opening Obsidian)
- Remind them: "Edit `Polaris/top-of-mind.md` to keep alignment signals accurate for future sessions"
